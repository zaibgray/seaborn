# Seaborn Notebook

This is my personal notebook where I'm learning Seaborn. I made it mainly for myself, but sharing it here in case it helps someone else too.

It's a collection of notes and code examples covering the Seaborn concepts I use most often for **Data Science, Data Analysis, EDA, Machine Learning, and AI**.

## What's inside

* **Getting Started** — importing Seaborn, NumPy, Pandas, and Matplotlib
* **Seaborn Basics** — understanding Seaborn and its Axis-level and Figure-level functions
* **Relational Plots** — `lineplot()`, `scatterplot()`, and `relplot()` for trends and relationships
* **Distribution Plots** — `histplot()`, `kdeplot()`, and `displot()` for understanding numerical distributions
* **Categorical Plots** — `barplot()`, `boxplot()`, `countplot()`, and `catplot()` for categorical data
* **Regression Plots** — `regplot()`, `residplot()`, and `lmplot()` for regression trends and residuals
* **Matrix Plots** — `heatmap()` for visualizing matrices and correlations
* **Multi-Plot Grids** — `pairplot()` and `jointplot()` for exploring multiple variables and relationships
* **FacetGrid** — creating multiple plots based on subsets of data
* **Figure-level vs Axis-level** — understanding when to use each type of Seaborn function
* **Data-Type Guide** — choosing plots based on numerical and categorical data
* **Quick Plot Selection** — choosing the right Seaborn plot for common EDA tasks
* **Seaborn vs Matplotlib** — comparing the common parameters and workflows used in both libraries
* **Daily-Use Parameters** — `data`, `x`, `y`, `hue`, `style`, `size`, `color`, `palette`, `marker`, `alpha`, `linewidth`, `bins`, `order`, `hue_order`, and more

(This list matches what's currently in the notebook — update it if you add more topics.)

## How to use it

1. Clone the repo:

```bash
git clone https://github.com/zaibgray/seaborn.git
cd seaborn
```

2. Install the required libraries:

```bash
pip install seaborn numpy pandas matplotlib jupyter
```

3. Open the notebook:

```bash
jupyter notebook
```

Then just run the cells one by one.
